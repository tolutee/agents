I wrote a Python program in the sandbox to compute the first 1,000,000 terms of the Leibniz series and multiply the total by 4.

What I did:
- Created `leibniz_pi.py`
- Used Python’s `decimal` module for high precision
- Summed the first 1,000,000 terms of:
  `1 - 1/3 + 1/5 - 1/7 + ...`
- Multiplied the final total by 4
- Ran the script in the sandbox

Final result:
`3.1415916535897932387126433832791903841971703525036`
